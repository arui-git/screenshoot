# 桌面截图工具（Python + PyQt6）

这是一个类似 QQ 截图的轻量桌面截图软件，支持：

- 区域选择（暗屏、拖拽、移动、边框缩放、尺寸显示）
- 单次截图（PNG 自动命名保存）
- 连续截图（长按 `F8` 开始，松开停止）
- 最近截图历史（最多 10 张缩略图，点击可打开）
- 快捷键操作（`Ctrl+Shift+S`、`Enter`、`R`、`F8`）

---

## 1. 功能说明（给使用者）

### 1.1 开始截图

- 点击主界面 **开始截图**
- 或快捷键 **Ctrl + Shift + S**

进入截图模式后：

- 屏幕会变暗
- 鼠标拖动可创建选区
- 选区支持：
  - 拖动移动
  - 八方向边框点缩放
  - 显示当前区域尺寸（如 `1200 × 800`）

### 1.2 单次截图

选区确定后可触发截图：

- 点击 **截图** 按钮
- 或在截图层按 **Enter**

保存格式：

- `PNG`

命名规则：

- `screenshot_YYYYMMDD_HHMMSS.png`
- 同一秒内多张会自动追加后缀，避免覆盖（例如 `_1`、`_2`）

### 1.3 连续截图

- 长按 **F8**：按固定间隔持续截图
- 松开 **F8**：停止连续截图
- 间隔默认 `500ms`，最小支持 `100ms`（可在设置中修改）

### 1.4 历史截图

主界面展示最近 10 张截图缩略图：

- 点击缩略图：用系统默认图片查看器打开
- 点击 **打开截图目录**：打开保存路径

## 2. 默认快捷键

- 开始截图：`Ctrl + Shift + S`
- 截图：`Enter`（在截图层可直接截图）
- 重新选择：`R`（在截图层）
- 连续截图：长按 `F8`

## 4. 关键模块说明

### 4.1 ScreenCapture（`core/screen_capture.py`）

- 管理多显示器虚拟桌面范围
- 按全局坐标抓取选区截图
- 对部分平台截图失败场景提供回退逻辑

### 4.2 RegionSelector（`ui/region_selector.py`）

- 截图遮罩层（暗屏）
- 区域拖拽创建、移动、缩放
- 实时尺寸显示
- `Enter` 确认并触发截图，`R` 重选，`Esc` 退出

### 4.3 HotkeyManager（`services/hotkey_manager.py`）

- 全局监听快捷键（基于 `pynput`）
- 触发开始截图
- 监听 `F8` 按下/释放，控制连续截图开始与停止

### 4.4 ImageSaver（`core/image_saver.py`）

- 统一管理保存目录
- 生成文件名并保存 PNG
- 自动避免重名覆盖

### 4.5 HistoryManager（`core/history_manager.py`）

- 读取指定目录中的最近截图
- 返回最近 N 张（默认 10 张）

### 4.6 UI（`ui/main_window.py`）

- 主窗口按钮与流程调度
- 单次/连续截图控制
- 历史缩略图渲染与打开
- 设置（保存目录、连续截图间隔）

## 7. 截图流程（与需求一致）

启动软件  
→ 点击开始截图（或 Ctrl+Shift+S）  
→ 屏幕变暗并拖动选择区域  
→ 调整选区（移动/缩放）  
→ Enter 或“截图”按钮触发  
→ 自动保存 PNG  
→ 历史列表更新并可点击打开

---

## 8. 性能与兼容说明

- 设计目标：截图延迟 < 100ms（与系统、分辨率、显示协议有关）
- 连续截图最小间隔：100ms
- 支持多显示器虚拟桌面坐标

---

## 9. 已知边界

- 在部分 Linux Wayland 环境下，系统可能限制全局快捷键或屏幕抓取权限；建议在 X11 或允许截屏权限后使用。
